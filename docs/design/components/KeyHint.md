# KeyHint

Shows a keyboard shortcut next to the control it triggers, and in the shortcut sheet.

- **Provide:** the key label (`A`, `Enter`, `/`).
- **Use:** inside buttons in the DecisionBar, in the queue's empty and help states, and in the sheet opened with `?`. The shortcut set is fixed: `J`/`K`, `Enter`, `A`, `O`, `E`, `X`, `/`, `?`.
- **Do:** keep shortcuts single keys, active only when focus is not in a text field.
- **Don't:** introduce chorded shortcuts or reuse a key for a different action on another screen.
